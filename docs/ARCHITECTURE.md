## 2. 代码模块

### 2.1 核心引擎 (`minecraft-3d.js`)

| 模块 | 行数 | 说明 |
|------|------|------|
| 配置与常量 | ~100 | 游戏参数、方块类型定义 |
| 音频系统 | ~60 | Web Audio API 音效合成 |
| TTS 语音 | ~100 | 浏览器语音合成、多语音切换 |
| 拼音系统 | ~200 | 中文-拼音映射、ruby 标注 |
| 游戏状态 | ~200 | 玩家数据、物品栏、装备 |
| 世界生成 | ~500 | 地形、资源、纹理加载 |
| 渲染系统 | ~400 | Three.js 场景、光照、雾效 |
| 物理系统 | ~200 | 重力、碰撞、跳跃 |
| 战斗系统 | ~400 | 攻击、伤害、怪物 AI |
| 合成系统 | ~300 | 工作台、配方管理 |
| UI 系统 | ~500 | 面板、对话框、HUD |
| 教育系统 | ~400 | 关卡、XP、朗读 |
| 存档系统 | ~100 | localStorage 读写 |
| 动画/粒子 | ~200 | 环境粒子、特效 |

## 3. 数据流

### 3.1 游戏主循环

```
animate()  [每帧]
  │
  ├── delta = 计算帧间隔
  ├── gameTime += delta
  │
  ├── updatePhysics(delta)     [玩家移动/跳跃/碰撞]
  ├── updateMobs(delta)        [怪物 AI/追击/逃跑]
  ├── updateWorld()            [区块加载/卸载]
  ├── updateParticles(delta)   [环境粒子]
  ├── updateUI()               [HUD 刷新]
  │
  └── renderer.render()        [Three.js 渲染]
```

### 3.2 存档数据流

```
游戏数据 (内存)
  │
  ├── saveGame()               [手动保存]
  │     └── localStorage.setItem('minecraft3d_save', JSON.stringify(data))
  │
  ├── loadGame()               [启动时读取]
  │     └── JSON.parse(localStorage.getItem('minecraft3d_save'))
  │
  └── 自动保存                 [每 30 秒]
        └── saveGame()
```

### 3.3 教育关卡流程

```
玩家进入副本传送门
  │
  ├── 加载关卡数据 (教材题库)
  │     └── 语文/数学/英语 分科题目
  │
  ├── 显示题目 + TTS 朗读
  │     └── speakText(题目内容)
  │
  ├── 玩家答题
  │     ├── 正确 → addXP() + 播放成功音效
  │     └── 错误 → 显示提示 + 重试
  │
  └── 完成关卡
        └── 更新学习等级 + 解锁下一关
```

## 4. 文件依赖关系

```

  ├── <link> → minecraft-3d.css
  ├── <script> → minecraft-3d.js
  │
  └── minecraft-3d.js

        ├── fetch('教材/二年级上册/*.txt')     [教材数据]
        └── localStorage                     [存档]
```

## 5. 性能优化

| 优化项 | 方法 |
|--------|------|
| 区块加载 | 只渲染玩家附近的区块 |
| 纹理图集 | 合并纹理减少 draw call |
| 粒子限制 | 环境粒子数量上限 |
| 存档节流 | 每 30 秒保存一次 |
| TTS 分段 | 长文本分段朗读避免中断 |
| 语音缓存 | 缓存语音列表避免重复加载 |
